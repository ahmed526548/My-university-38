# Electronics – Section 4
## ملخص وشرح المحاضرة

### 1) المقاومة الكهربائية (Resistance)
المقاومة خاصية المادة التي تعارض مرور التيار الكهربائي، ورمزها R ووحدتها الأوم (Ω).

مقاومة مادة منتظمة المقطع:
`R = ρℓ/A`

- ρ: المقاومية النوعية (Ω·m)
- ℓ: الطول (m)
- A: مساحة المقطع (m²)

زيادة طول المادة تزيد مقاومتها، وزيادة مساحة المقطع تقلل مقاومتها.

### 2) قانون أوم (Ohm’s Law)
`V = IR`
ومنها: `I = V/R` و `R = V/I`.

مثال: مقاومة 4 Ω موصلة بجهد 12 V:
`I = 12/4 = 3 A`.

### 3) اتفاقية الإشارة (Passive Sign Convention)
إذا دخل التيار إلى الطرف الموجب للمقاومة وخرج من الطرف السالب: `V = IR`.
إذا كانت مراجع اتجاه التيار وقطبية الجهد متعاكسة وفق تعريف المسألة: `V = -IR`.
حدد الاتجاه والقطبية أولًا والتزم بهما.

### 4) أنواع المقاومات
- Fixed Resistor: مقاومة ثابتة.
- Variable Resistor: مقاومة يمكن تغيير قيمتها.

### 5) التوصيلية (Conductance)
مقلوب المقاومة، ورمزها G:
`G = 1/R`
وحدتها السيمنز (S)، ويُستخدم أيضًا mho.

مثال: إذا كانت R = 5 Ω فإن G = 0.2 S.

### 6) العقد والفروع والحلقات
- Node: نقطة اتصال فرعين أو أكثر.
- Branch: جزء يحتوي عنصرًا واحدًا مثل مقاومة أو مصدر جهد.
- Loop: مسار مغلق يبدأ وينتهي عند النقطة نفسها.

### 7) التوالي والتوازي
**التوالي (Series):** التيار نفسه يمر في العناصر:
`Req = R1 + R2 + ...`

**التوازي (Parallel):** الجهد نفسه على العناصر:
`1/Req = 1/R1 + 1/R2 + ...`
ولمقاومتين:
`Req = (R1 × R2)/(R1 + R2)`

مثال: 2 Ω و3 Ω:
- توالي: 5 Ω
- توازي: 1.2 Ω

### 8) قانون كيرشوف للتيار (KCL)
مجموع التيارات الداخلة إلى أي عقدة يساوي مجموع التيارات الخارجة:
`ΣI(in) = ΣI(out)`.

### 9) قانون كيرشوف للجهد (KVL)
المجموع الجبري لفروق الجهد حول أي مسار مغلق يساوي صفرًا:
`ΣV = 0`.

### خطوات حل مسائل الدوائر
1. اقرأ الرسم وحدد العناصر والقيم واتجاهات التيار وقطبية الجهد.
2. استخدم قانون أوم عند الحاجة.
3. استخدم KCL لحساب التيارات عند العقد.
4. استخدم KVL لحساب الجهود حول الحلقات.
5. التزم باتفاقية الإشارات.
6. راجع الوحدات: V للجهد، A للتيار، Ω للمقاومة، وS للتوصيلية.

### ورقة القوانين السريعة
- `V = IR`
- `I = V/R`
- `R = V/I`
- `R = ρℓ/A`
- `G = 1/R`
- `Req(series) = R1 + R2 + ...`
- `Req(parallel) = (R1R2)/(R1+R2)` لمقاومتين
- `ΣI(in) = ΣI(out)`
- `ΣV = 0`
